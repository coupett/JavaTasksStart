## Задача: «Система учёта студентов»

### Описание

Тебе нужно написать программу, которая:

1. Хранит данные о нескольких студентах.
2. Позволяет выбрать студента по номеру.
3. Для выбранного студента:
    - выводит его имя, возраст, средний балл;
    - определяет его статус (отличник, хорошист и т.д.);
    - считает сумму и среднее его оценок;
    - находит максимальную и минимальную оценку;
    - проверяет, есть ли у него хотя бы одна двойка.

______________________________________________________________________

### Требования к коду

#### 1. Переменные и типы данных

Создай следующие переменные:

- `String[] names` — массив имён студентов;
- `int[] ages` — массив возрастов;
- `double[] averages` — массив средних баллов каждого студента;
- `int[][] grades` — массив оценок (двумерный: для каждого студента свой массив оценок);
- `int selected` — номер выбранного студента (индекс в массивах);
- `char statusSymbol` — символ, обозначающий статус студента (`'A'`, `'B'`, `'C'`, `'D'`);
- `boolean hasTwo` — флаг, есть ли у студента хотя бы одна двойка.


#### 2. Исходные данные

Заполни массивы вручную, например:

```java
String[] names = {"Алекс", "Борис", "Вика", "Дима"};
int[] ages = {20, 21, 19, 22};
double[] averages = {4.8, 3.9, 4.2, 3.5};

int[][] grades = {
    {5, 5, 4, 5, 5},   // Алекс
    {4, 3, 4, 4, 3},   // Борис
    {5, 4, 4, 5, 3},   // Вика
    {3, 3, 2, 4, 3}    // Дима
};
```


#### 3. Выбор студента

Создай переменную:

```java
int selected = 2; // например, выбираем третьего студента (индекс 2)
```

Проверь, что индекс корректен:

- если `selected < 0` или `selected >= names.length`, выведи сообщение:

```text
Некорректный номер студента
```

и заверши программу (можно просто `return;`).


#### 4. Вывод основной информации

Выведи:

```text
Студент: <имя>
Возраст: <возраст>
Средний балл: <средний>
```


#### 5. Определение статуса через `switch-case`

Определи статус студента по среднему баллу:

- `average >= 4.5` → статус `'A'` (отличник);
- `4.0 <= average < 4.5` → статус `'B'` (хорошист);
- `3.5 <= average < 4.0` → статус `'C'` (удовлетворительно);
- иначе → статус `'D'` (неудовлетворительно).

Сохрани результат в переменную:

```java
char statusSymbol;
```

Затем с помощью `switch-case` выведи текстовое описание:

- `'A'` → `"Статус: Отличник"`;
- `'B'` → `"Статус: Хорошист"`;
- `'C'` → `"Статус: Удовлетворительно"`;
- `'D'` → `"Статус: Неудовлетворительно"`;
- другой символ → `"Статус: Неизвестно"`.


#### 6. Работа с оценками (циклы и массивы)

Для выбранного студента:

- получи массив его оценок:

```java
int[] studentGrades = grades[selected];
```

- с помощью цикла `for` (обычного или `for-each`) найди:
    - сумму всех оценок;
    - среднее арифметическое оценок;
    - максимальную оценку;
    - минимальную оценку.
- с помощью цикла `for-each` определи, есть ли хотя бы одна двойка:

```java
boolean hasTwo = false;
for (int g : studentGrades) {
    // если g == 2, установи hasTwo = true
}
```

После цикла выведи:

```text
Есть хотя бы одна двойка: <true/false>
```


#### 7. Итоговый вывод

Программа должна вывести что‑то вроде:

```text
Студент: Вика
Возраст: 19
Средний балл: 4.2
Статус: Хорошист
Сумма оценок: 21
Среднее оценок: 4.2
Максимальная оценка: 5
Минимальная оценка: 3
Есть хотя бы одна двойка: false
```

(конкретные значения зависят от выбранного студента).

### Темы, которые ты здесь используешь

- Переменные и типы данных: `String`, `int`, `double`, `char`, `boolean`, массивы.
- Условные операторы: `if`, сравнения, логические условия.
- Циклы: `for`, `for-each`.
- Массивы: одномерные и двумерные.
- `switch-case`: для расшифровки статуса по символу.
- Арифметика: сумма, среднее, поиск максимума/минимума.
